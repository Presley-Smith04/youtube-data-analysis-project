# Data Engineering YouTube Analysis Project

This project builds a scalable data engineering pipeline to analyze youtube trending video data across multiple regions. 

Using aws services, it takes raw structured and semi structured data, transforms it through an etl process, and stores it in a centralized data lake on amazon s3. 

Tools like AWS glue and lambda automate processing, while AWS athena enables querying directly from s3. 

the processed data is then visualized using quicksight dashboards to uncover insights on video performance, categories, and engagement trends.

Overall, the system is designed to be efficient, secure, and able to scale with growing data volumes.
